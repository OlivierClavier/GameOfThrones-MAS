# GameOfThrones MAS

A multi-agent system (MAS) simulation in Java in the universe of Game Of Thrones

## Lancer le projet

Prérequis : JDK 21 et Maven (IntelliJ inclut Maven).

```bash
mvn package
java -jar target/got-mas.jar
```
